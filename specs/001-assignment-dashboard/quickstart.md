# Quickstart: assignment-dashboard

## 목적
이 문서는 대학생용 과제 마감 대시보드 기능의 검증 시나리오를 설명한다.

## 전제
- 최신 브라우저에서 실행 가능한 정적 웹 앱 형태
- IndexedDB를 통해 로컬 데이터를 유지
- 테스트는 Vitest 또는 유사 테스트 도구로 실행

## 검증 시나리오

1. **과제 등록 및 저장**
   - 과목을 생성하고 색상을 선택한다.
   - 과제 제목, 설명, 마감일/시간을 입력하고 과목을 선택하여 과제를 추가한다.
   - 페이지를 새로 고침하거나 앱을 재시작해도 과제가 유지되는지 확인한다.

2. **연체 및 마감 임박 표시**
   - 마감일이 지나간 과제는 연체 상태로 표시되는지 확인한다.
   - 마감일이 3일 이내인 과제는 경고 상태로 강조되는지 확인한다.

3. **완료 처리 및 목록 정렬**
   - 과제를 완료로 표시하고, 완료된 과제가 목록 하단에 모여 표시되는지 확인한다.
   - 연체 과제가 최상단에 표시되고, 그 다음 마감 임박 과제가 정렬되는지 확인한다.

4. **과목 필터**
   - 과목별 필터를 선택하고 해당 과목 과제만 표시되는지 확인한다.

5. **완료율 요약**
   - 전체 과제 대비 완료 과제 비율이 요약 영역에 정확히 표시되는지 확인한다.

## 실행 방법
- 개발 서버나 정적 파일 서버로 `src/index.html`을 열기
- `Vitest`를 설치한 경우 `npx vitest run` 또는 `npm test`로 테스트 실행

## 기대 결과
- UI가 명확하게 렌더링되고 과제 상태가 정확하게 구분됨
- 로컬 데이터가 앱 재시작 후에도 유지됨
- 완료율이 전체/완료 과제 비율로 정확히 표시됨
