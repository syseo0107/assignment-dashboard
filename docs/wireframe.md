# Dashboard Wireframe

다음은 대학생용 과제 마감 대시보드의 텍스트 와이어프레임입니다.

```
+---------------------------------------------------------------+
| 완료율 요약 영역                                               |
| ------------------------------------------------------------- |
| 완료율: 82%      전체 과제: 12      완료된 과제: 10          |
| 상태 요약: 경고 2개, 연체 1개                                    |
+---------------------------------------------------------------+

+---------------------------------------------------------------+
| 과목 필터                                                      |
| ------------------------------------------------------------- |
| [전체]  [프로그래밍]  [수학]  [영어]  [전공]                     |
+---------------------------------------------------------------+

+---------------------------------------------------------------+
| 과제 목록 (연체 > 마감 임박 > 완료)                              |
| ------------------------------------------------------------- |
| [ ] [회색] 과목: 영어             | 영어 에세이 제출         | D+2 |    |
|     - 마감이 지난 과제로 연체 표시(연체 텍스트 또는 색상 강조)      |
|                                                               |
| [ ] [빨간색] 과목: 프로그래밍       | 알고리즘 과제 1          | D-1 |    |
|     - 마감 3일 이내 과제로 경고 색상 처리                          |
|                                                               |
| [ ] [파란색] 과목: 수학             | 통계 퀴즈 준비           | D-3 |    |
|     - 마감 3일 이내 과제로 경고 색상 처리                          |
|                                                               |
| [ ] [노란색] 과목: 프로그래밍      | 팀 과제 문서 작성        | D-7 |    |
|     - 마감이 남은 일반 과제로 기본 표시                           |
|                                                               |
| [x] [초록색] 과목: 전공             | 프로젝트 보고서         | 완료    |    |
|     - 완료된 과제는 목록 하단에 모아서 표시                        |
+---------------------------------------------------------------+
```

- 상단 완료율 요약 영역: 전체 과제 대비 완료 과제 비율과 주요 상태 요약을 표시합니다.
- 과목 필터: 선택한 과목별로 과제 목록을 필터링할 수 있는 버튼 모음입니다.
- 과제 목록 항목:
  - 왼쪽에 완료 체크박스
  - 과목 색상 표시 영역
  - 과제 제목
  - D-Day 배지
  - 경고/연체 상태는 해당 항목의 배경 또는 텍스트 색상으로 시각적으로 구분합니다.
  - 완료된 과제는 체크표시와 함께 기본 활성 목록에서 쉽게 구분됩니다.
